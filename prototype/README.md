# 本地原型：自动代练

直接双击 `index.html` 用浏览器打开，不需要安装，也不联网。数据存在浏览器 localStorage，点顶部"重置"恢复演示数据。

这是业务规则的可运行验证版，不是生产代码。正式实现按 `docs/` 中的设计在 Dujiao-Next 的 Go 代码中完成。

## 三个视角

| 视角 | 内容 |
|---|---|
| 用户端 | 发起代练（选游戏 → 选账号 → 选功能 → 按 JSON 自动生成的表单，含关卡选择、通关/扫荡、次数）、我的任务（步骤进度、日志、验证码输入、取消）、我的游戏账号（绑定、验证码）、积分 |
| 管理后台 | 游戏与代练功能（新建游戏、区服、上下线；功能 JSON 编辑器 + 结构校验 + 用户端实时预览 + 版本历史）、代练任务、积分与订单、执行端、审计、一致性校验 |
| 执行端模拟 | 扮演游戏 Worker：领取、心跳、上报日志、要验证码、完成、各类失败、确认取消。右侧显示每个签名请求和响应 |

顶部时间是虚拟时间，可以快进。勾选"执行端自动运行"后，模拟执行端每秒领取并推进任务。

## 建议体验顺序

1. 管理后台 → 游戏与代练功能 → 星落幻境 → 主线关卡"编辑"。改左边 JSON（比如改一个关卡的价格，或者加一章），右边预览马上变化。保存后版本 +1。
2. 点"新建：关卡（通关 / 扫荡）"，用模板做一个新功能，保存、上架。也可以"新建"一个游戏，加区服、加功能、上线。
3. 用户端 → 勾选"执行端自动运行" → 添加游戏账号 → 输入任意 6 位验证码 → 选"主线关卡"，选扫荡，勾几个关卡，调次数，看右侧报价 → 开始。
4. 我的任务 → 展开"步骤与日志"看执行进度。中途取消，只扣已完成部分。

## 文件

```text
src/catalog.js        代练功能 JSON 规范：校验、编译（可见性/默认值/报价/执行步骤）、结算
src/engine.js         基础设施、钱包、积分包订单、后台游戏/区服/功能管理
src/boost.js          积分账本、绑定、任务、Worker 协议、回收、不变量
src/seed.js           演示数据（6 个示例功能定义）
src/ui-form.js        按 JSON 渲染表单（用户端和后台预览共用）
src/ui-*.js           其它界面
build.js              打包成单文件 index.html
test/                 自动化测试
```

## 命令

```bash
node prototype/build.js
node --test prototype/test/catalog.test.js prototype/test/engine.test.js prototype/test/ui-smoke.test.js
```

## 和正式实现的差异

- 凭据"加密"是 base64 封装，只演示流程；正式实现用 AES-256-GCM 和独立密钥。
- 并发用串行调用 + 事务回滚模拟；数据库层的行锁和唯一索引要在 Go 版本里用 PostgreSQL 并发测试再验证。
- 支付网关、执行端都是模拟。
